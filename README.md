# Urban Forestry Asset Management System (UFAMS)

## Overview

UFAMS (Urban Forestry Asset Management System) is a full-stack municipal GIS application designed to manage urban forestry assets such as trees, inspections, maintenance activities, and work orders.

The project demonstrates enterprise software engineering practices commonly used by municipal governments and public sector organizations.

Although inspired by urban forestry workflows, the system is designed to showcase GIS programming, web application development, database design, automation, testing, documentation, and deployment.

---

## Objectives

This project aims to demonstrate proficiency in:

- GIS application development
- ArcGIS Maps SDK
- ASP.NET Core Web API
- React and TypeScript
- SQL Server
- Python GIS automation
- Enterprise software architecture
- REST API design
- Authentication and authorization
- CI/CD
- Automated testing
- Technical documentation
